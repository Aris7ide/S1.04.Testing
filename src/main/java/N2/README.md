# Nivel 2: AssertJ

## 📌 Enunciat del exercici
En este nivel aprenderemos a utilizar AssertJ , una biblioteca de testing que nos permite escribir aserciones más expresivas y legibles que las aserciones tradicionales de JUnit.

Cada ejercicio propuesto se centra en una funcionalidad distinta de AssertJ. Te recomendamos consultar la documentación oficial si necesita ayuda adicional durante la práctica.
