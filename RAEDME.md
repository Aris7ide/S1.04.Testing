# Tarea S1.04 - Testing

## 📌 Enunciat del exercici
Objetivos de la tarea
Esta tarea tiene como objetivo poner en práctica los conocimientos esenciales sobre el testing en Java, utilizando herramientas como JUnit 5 , AssertJ y la metodología TDD (Test-Driven Development) . A través de ejercicios guiados y progresivos, se busca que seas capaz de:

- Organizar correctamente un proyecto Java con Maven o Gradle , incluyendo las dependencias necesarias para realizar tests.
- Escribir y ejecutar pruebas unitarias con JUnit 5 para verificar el comportamiento de clases y métodos.
- Utilizar AssertJ para realizar aserciones claras, precisas y expresivas.
- Aplicar el ciclo de TDD (test, implementación, refactorización) en el desarrollo de funcionalidades básicas.
- Escribir código modular y testeable, separando claramente la lógica de negocio de los detalles de entrada/salida.

Recomendaciones generales:
- Utiliza un gestor de proyectos (Maven o Gradle) para añadir las dependencias necesarias.
- Crear las clases de tests en el package de Test correspondiente.
- Haz al menos un commit con un título relevante por ejercicio.
- Sigue el documento de buenas prácticas detallado en el Sprint 0 para cumplir las normas en las entregas de los repositorios de GitHub.
- Programa en inglés.
